# Relocated InnerTepenia-Specific Material

This folder holds the InnerTepeniaGDD-specific worked examples, named-character illustrations, and
district/game-mechanic content that was stripped out of `../methodology/` during the 2026-09-17 novel-fiction
adaptation pass, so it isn't lost — just moved out of the general, setting-agnostic methodology files.

None of this is authoritative here — it's a preserved copy of material that properly belongs with those
characters' own project files in the InnerTepeniaGDD repo (Calethina, Ayako Hayashi, Favi della Torre, Vosora
Lashár Tanslock, and others each already have, or should have, their own file there). If any of it is ever
needed for InnerTepenia game-design work, treat the InnerTepeniaGDD repo's own copies as the source of truth,
not these files.

## Contents

- `Stage4_Story_Material_Removed_Content.md` — the Calethina worked example and the Favi/Vosora/Ji-Eun Kim
  illustrations from the Player-Necessity Rule section, both originally in `04_Story_Material.md`.
- `Stage5_Beats_Paths_Results_Removed_Content.md` — the Calethina worked example (Midpoint through the Ending-
  Shape analysis), the Calethina-specific portions of the Trigger-Type Design Pattern, and the Favi/Vosora/
  Ayako/Michelle Stanton illustrations from the Branching Investigation-Route Structure section, all originally
  in `05_Beats_Paths_Results.md`.
