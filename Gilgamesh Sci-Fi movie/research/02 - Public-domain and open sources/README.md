# Public-domain and open sources for the Gilgamesh play-by-play (2026-10-25)

**Why this folder exists.** The author asked for existing play-by-play outlines from the internet, to fold into the notes without copyright problems. The finding: most online outlines (SparkNotes, Shmoop, SuperSummary, LitCharts, Britannica) are copyrighted as text too. What is free is the story's content itself, and translations old enough to be public domain. This folder holds the free sources that turned up. The rewrite pass (`../01 .../_dispatch/rewrite_brief.md`) uses them for quotations and as a cross-check.

## In this folder
| Source | Status | What it covers |
|---|---|---|
| **R. Campbell Thompson, trans., *The Epic of Gilgamish*** (London: Luzac, 1928), one file per tablet | **Public domain.** Thompson died in 1941, so UK copyright ended in 2012. Published 1928, so US public domain since 1 January 2024. | All twelve tablets, in English hexameters, from the British Museum tablets known in 1928. It is older than George's reconstruction, lacks every fragment found since, and often reads differently. |
| **Morris Jastrow Jr. and Albert T. Clay, *An Old Babylonian Version of the Gilgamesh Epic*** (Yale University Press, 1920), Project Gutenberg eBook 11000 | **Public domain in the US** (Gutenberg notice kept in the file) | The Old Babylonian Pennsylvania and Yale tablets (George's "P" and "Y"), with introduction and notes |
| **Wikipedia, "Epic of Gilgamesh"**, revision 1377304124: its tablet-by-tablet synopsis, Old Babylonian versions and Sumerian poems sections | **CC BY-SA 4.0.** Reuse needs attribution, and anything built from the text must carry the same license. So it is used here as a cross-check and paraphrased, not copied. | About 4,100 words. It says it is "based on Andrew George's translation," most likely an earlier edition than 2020. |

**Where the Thompson text came from.** sacred-texts.com (https://sacred-texts.com/ane/eog/) blocked automated download, so the text was taken from a public mirror of the same pages. The author offered to download the originals.
- If they are saved into `Thompson 1928 - The Epic of Gilgamish (public domain)/originals from sacred-texts/`, the mirror copy can be checked against them.
- The original page addresses are `https://sacred-texts.com/ane/eog/index.htm`, then `eog00.htm` (title page), `eog01.htm` (preface), `eog02.htm` (addenda), and `eog03.htm` to `eog14.htm` (Tablets I-XII).
