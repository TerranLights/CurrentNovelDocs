# Units

The unit library. One folder per unit (a regional culture, an ethnic identity or an Indigenous people), created at Stage 0 of the first target that contains it. Layout per unit: `README.md` (the unit, its lobe and its profile table), `01 - Lineage/` (eleven profile files), `02 - Measured data.md`, `03 - Five axes.md`, `04 - Signs/NN - <Sign>/` (one `00 - Domain and folkways.md`, then one file per concept). See the runbook.
