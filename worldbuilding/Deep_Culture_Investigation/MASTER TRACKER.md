# DCI master tracker

**Read this first when resuming any DCI work.** Update it whenever a target or unit changes status. The method (runbook, templates, shared lists) is in DerivationMechanisms `Environment/DCI [Deep Culture Investigation]/`.

Every target is researched at full depth (author, 2026-11-02). Order: the pilot and the first novels' nations first, then by number of exiles (the order after the first three is not a ruling). If the census changes, update this list.
