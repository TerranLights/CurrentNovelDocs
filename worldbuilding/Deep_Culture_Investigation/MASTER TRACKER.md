# DCI master tracker

**Read this first when resuming any DCI work.** Update it whenever a target or unit changes status. The method (runbook, templates, shared lists) is in DerivationMechanisms `Environment/DCI [Deep Culture Investigation]/`.

**Targets:** every origin in the Census I table of `Official_Population_Census.md` (Inner Tepenia GDD), as of 2026-11-02: 81 nations, plus Sicilia (an autonomous zone within Meridia) and the southern Ontario DMZ (not a nation). Every target is researched at full depth (author, 2026-11-02). Order: the pilot and the first novels' nations first, then by number of exiles (the order after the first three is not a ruling). If the census changes, update this list.

## Targets
**Folders (2026-11-15):** targets are grouped by region: `Targets/<region>/<nation>/` (for the four Asian regions, `Targets/Asia/<region>/<nation>/`), using the Region column below (Africa, Asia, Europe, Latin America, North America, Oceania, Russia; the Asia folder holds the Central Asia, East Asia, Mainland Southeast Asia and Maritime Southeast Asia regions). Each nation has its `PROGRESS TRACKER.md`, `05 - Composite/` and `06 - Divergence/`; `00 - Scope.md` is added at Stage 0. The folder carries the nation's name; four rows drop their parenthetical note (Argentina, Russia, Demilitarized Zone, Sicilia). The Russia region holds twelve successor states, including the nation Russia itself (`Targets/Russia/Russia/`). **Greenland (#84)** was added 2026-11-15: it is a New North America region with no Census I exiles, so it was not a census row. Regions follow the countries checklist (Part C).
