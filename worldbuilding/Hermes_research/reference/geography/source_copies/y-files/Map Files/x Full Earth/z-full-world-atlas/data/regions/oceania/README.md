# Oceania - region data for the world atlas

Output: `nations.gpkg` (layer `nations`, 23 rows, EPSG:4326, longitudes in -180..180), `build_oceania.py` (reproducible), `preview.png` (2400 px, shifted +360 for the preview only so the Pacific reads continuously; the data itself is -180..180).

## What was used (state treated as final)
- Source folder: `Oceania/` (read-only). The final state is the **flat-color pass, round 3** (`CHANGES.md`, 2026-09-26): `render_map_oceania_continental.py` and `render_map_oceania_islands.py` (Sep 27 copies; byte-identical to the ones inside `files.zip`) and `subdivisions.csv`/`spheres.csv`. The round 3 pass changed only the drawing (removed hatch fills), not the unit-to-nation assignment, so the earlier rounds are identical for this data. `instructions.zip` holds the older Sep 26 copies of the scripts and was not used.
- Which unit belongs to which nation: the scripts' ISO-to-nation tables plus `subdivisions.csv` (the build asserts that every CSV unit is found in Natural Earth admin-1 and vice versa; both pass). Borders: Natural Earth 10m admin-1 (`/tmp/ne_test/`), dissolved per nation. No borders were re-derived.
- Colors: `color` is the `color_hex` of `subdivisions.csv` (the nation's base color). The source maps draw it lightened by 42 percent toward white (`lighten()`), so a map built from the atlas should lighten it the same way to match.
- Capitals: those the scripts mark as capitals (Canberra, Wellington, Port Moresby, Honiara, Port Vila, Suva, Noumea, Palikir, Majuro, Ngerulmud, Yaren, Tarawa, Apia, Nuku'alofa, Funafuti). Coordinates are as given in the scripts (Samoa and Tonga longitudes wrapped from 188.22 and 184.78 to -171.78 and -175.22). The scripts mark Papeete (French Polynesia) and Hagatna (Guam) only as cities, so those two are left empty; Cook Islands, Niue, American Samoa, Northern Mariana Islands, Wallis and Futuna, Pitcairn Islands have no capital in the source.
- `native` is empty everywhere (the source documents no native names). `kind` = `nation` for the 14 nations the islands map lists as sovereign (including Australia, New Zealand, Papua New Guinea) and `provisional nation` for the 9 the source flags "AUTHOR DECISION NEEDED". `group` = sphere (Melanesia, Micronesia, Polynesia), `group_role` = `sphere`; Australia has no sphere. Kiribati is placed whole under Micronesia, as the source script does.

## Antimeridian
Natural Earth already splits features at +/-180, so Fiji (Eastern, Northern divisions), Kiribati, Tonga, Samoa, American Samoa, Wallis and Futuna, Tuvalu, the Chathams, the Kermadecs and Tokelau come out as valid polygons with parts on both sides of the line and none wider than 180 degrees (asserted in the build). Nothing was shifted or re-cut. Fiji's pieces meet at exactly +180 / -180 (a hairline seam in projections centered on the antimeridian is possible only if a renderer does not close it). (computed)

## Caveats and seams
- Kiribati: Natural Earth has two features, "Kiribati" and one with no name (the Line Islands, -174.5 to -155.9). The source scripts dissolve by name, so the unnamed one could have been dropped there; the source map does show Kiritimati, and the CSV's single Kiribati row stands for the whole country, so both are included. `units` = 2 vs 1 CSV row.
- Overlaps inside the region: none (checked, computed). Gaps: none beyond the open sea.
- Hawaii (North America extraction) and West Papua (Southeast Asia) are not included, as instructed. Rapa Nui/Easter Island is named in the source only as out of scope (Chile, Latin America). Australia's Macquarie Island (-54.75) is the southern extreme; the Antarctic Australian claim is not included (source does not draw it).
- Seams with neighbors: Papua New Guinea borders Indonesia's West Papua on the 141st meridian (Southeast Asia extraction); the source drew Natural Earth's own PNG border, so the two regions should meet there but may differ by the geometry vintage each used. Pacific US/French/UK territories are provisional defaults flagged by the author in `subdivisions.csv`; if another region (North America, Europe) later claims Guam, Northern Mariana Islands, American Samoa, New Caledonia, French Polynesia, Wallis and Futuna or Pitcairn, the merge should resolve that by name (note, memory: the source says no successor state exists yet).
- Author decisions the source leaves open (not resolved here): the nine provisional territories above; Cook Islands and Niue could fold into New Zealand; Pitcairn could be tied to New Zealand; American Samoa could reunify with Samoa; Norfolk Island folded into Australia is lower confidence.
- Preview verified against `oceania_continental_map.png` and `oceania_islands_map.png` nation by nation: shapes and unit membership agree, including Chathams, Kermadecs, Tokelau and Macquarie in the right nations. Some labels in the preview overlap (Samoa, American Samoa, Wallis and Futuna) because the islands are tiny. Remaining mismatches: none found.
